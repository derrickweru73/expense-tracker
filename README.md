# Smart Expense Tracker

## Project Overview

Smart Expense Tracker is a modern, responsive, and lightweight web application built using HTML5, Tailwind CSS, and JavaScript. The application helps users record, organize, and monitor their daily expenses while providing real-time spending insights.

The system enables users to add expenses, categorize transactions, filter spending records, calculate total expenses, and maintain persistent financial records using Local Storage.

---

## Problems It Solves

Many individuals struggle to keep track of their daily spending, making it difficult to understand where their money goes. This application addresses several common financial challenges:

* Untracked daily expenses
* Poor budgeting habits
* Forgotten small purchases
* Difficulty identifying spending patterns
* Lack of financial awareness
* Inconsistent saving habits

By providing a simple expense management system, users can make more informed financial decisions.

* Organize expenses into categories such as:

  * Bills

### Expense Filtering

* Filter expenses by category
* Quickly analyze spending behavior

### Total Expense Calculation

* Automatically calculate total spending
* Update totals whenever expenses are added or removed

* Save expense records using Local Storage
* Maintain data after browser refreshes

* Mobile-friendly design
* Clean and intuitive dashboard
